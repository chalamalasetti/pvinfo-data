# PV Info public data

Public, checksum-pinned data snapshots behind [www.pvinfo.org](https://www.pvinfo.org) — the external drug-safety and regulatory intelligence hub that feeds your PV workflow — and the scheduled jobs that collect them.

- **Data:** each dataset lives on its own branch. The `main` branch holds only the job definitions and this documentation.
- **Jobs:** GitHub Actions workflows in this repository collect from official public sources (FDA, EMA, MHRA, Health Canada, PMDA and other regulators), check the result and publish it here. The site reads the published files.
- **Everything here is public information.** Each dataset's `manifest.json` lists its sources, collection dates, limits and checksums. No personal data and no case-level reports are stored.

## Datasets

| Branch | What it holds |
|---|---|
| `fda-feed-cache` | Latest collected FDA and regulator updates feed (`fda-feeds.json`) |
| `safety-data-cache` | Weekly product safety snapshot: openFDA adverse event counts, labels, recalls, shortages and signal candidates per ingredient |
| `approvals-data-cache` | Approval history across markets (Drugs@FDA and others) |
| `regulatory-dates-cache` | Regulatory calendar: consultations, decisions, data lock points and other agency dates |
| `codex/country-products-cache` | Normalized country product registers (for example EMA Article 57), gzip shards and a manifest |
| `product-data-cache` | Company registry and substance-to-product links |
| `clinical-data-cache` | Public clinical trial portfolios per company |
| `evidence-data-cache` | Evidence repository manifest; large files are attached to releases named `evidence-…` |
| `literature-data-cache` | Bibliographic metadata for the literature watch (only when enabled) |
| `regulatory-document-cache` | Key information extracted from archived public regulatory documents |
| `document-text-cache` | Plain text of archived public regulatory documents, used for requirement curation |
| `curated-requirements` | Checked requirement curation payloads, loaded into the PV Info database |

Details, file formats and how to cite: [docs/datasets.md](docs/datasets.md).

## Jobs and schedules

All workflows run here because public repositories get GitHub Actions minutes free. Schedules, triggers and how to run a job by hand: [docs/jobs.md](docs/jobs.md). Maintainer setup and troubleshooting: [docs/operations.md](docs/operations.md).

The workflows in `.github/workflows/` (except `sync-jobs.yml`) are generated by `scripts/build-jobs.mjs` from the job definitions maintained with the PV Info application, and are rebuilt by the **Sync jobs from PV-Info** workflow. Do not edit generated files here.

## Using the data

Read files straight from a branch, for example
`https://raw.githubusercontent.com/chalamalasetti/pvinfo-data/safety-data-cache/manifest.json`.
Branches are force-updated as new snapshots are published, so pin to a commit SHA if you need a stable copy. Data are provided as collected from the named public sources, with their dates and limits; they are not medical advice and do not replace the official source.
