# PV Info public data

Published, checksum-pinned data snapshots that www.pvinfo.org reads. Each branch holds one dataset; manifest.json in each branch lists sources, dates, limits and checksums. Written only by automated collection jobs.

## Scheduled jobs

PV Info's data refreshes, document capture, curation publishing and the code repository's pull request checks run here, because public repositories get GitHub Actions minutes free. The workflows in `.github/workflows/` (except `sync-jobs.yml`) are generated by `scripts/build-jobs.mjs` from the private code repository's job definitions and check out that code for each run with a read-only token. Do not edit generated files here; the **Sync jobs from PV-Info** workflow rebuilds them every 2 hours or on demand.
